# Planning Architecture

Status: APPROVED

Version: V4

---

# Purpose

Define the Planning Layer of Wafferly.

Planning explains money.

Planning never owns money.

---

# Planning Layer

Contains:

- Allocations
- Goals
- Budgets
- Reservations
- Virtual Saving

---

# Core Principle

Accounts own money.

Planning represents intent.

---

# Allocations

Planning Source Of Truth.

Allocations represent intent.

Allocations never own money.

---

# Goals

Represent purpose.

Goals answer:

Why am I saving this money?

Goals never own money.

---

# Budgets

Represent spending control.

Budgets never own money.

Budgets monitor spending.

---

# Reservations

Represent money separated for planning purposes.

Reservations do not move money.

Reservations do not create money.

Reservations do not delete money.

---

# Virtual Saving

Projection Layer concept.

Purpose:

Provide a unified dashboard for reserved money.

Virtual Saving owns no money.

---

# Funding Sources

Represent current funding state.

Funding Sources are projections.

Funding Sources are not stored.

---

# Goal Funding Architecture

Funding Sources
↓
Current State

Activities
↓
History

Goal Progress
↓
Achievement

---

# Budget Funding Architecture

Funding Sources
↓
Current State

Activities
↓
History

Budget Remaining
↓
Consumption Capacity

---

# Transfer To Saving

Real financial operation.

Creates:

- Transfer Transactions
- Goal Activities
- Allocation Releases

Creates no Saving Allocations.

---

# Summary

Accounts own money.

Planning explains intent.

Goals explain purpose.

Budgets monitor spending.

Allocations are planning truth.

Virtual Saving is a projection.
