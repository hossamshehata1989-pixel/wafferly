# Financial Rules

## Source of Truth

Accounts + Transactions are the only real balances.

## Members

Members are actors/participants, not financial containers.

## Goals

Goals are allocation layers, not real balances.

## Reserved Money

Reserved money does not reduce actual balance.
It reduces available balance only.

## Budgets

Budgets are allocation/policy layers.

## Analysis

Analysis is derived data only.

## Archive

Financial entities should be archived, not deleted.
